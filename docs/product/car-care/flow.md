# فلوی اپلیکیشن نگهداری خودرو

> دو نمودار: **فلوی فعلی** (همان که فرستادی، بازکشیده و شکاف‌هایش علامت‌خورده) و **فلوی پیشنهادی MVP**.
> علامت ❌ = گره یا مسیری که در طرح فعلی وجود ندارد و باعث شکستن تجربه می‌شود.

## ۱. فلوی فعلی (بازکشی‌شده)

### شکاف‌های این فلو

| # | شکاف | چرا می‌شکند |
|---|---|---|
| ۱ | **مدل خودرو پیدا نشد** | بن‌بست کامل. باید «نزدیک‌ترین مدل + برچسب تخمینی» داشته باشد. |
| ۲ | **کیلومتر نامعلوم** | فیلد اجباری. باید «نمی‌دانم» با حدس از سال خودرو. |
| ۳ | **رد کردن هشدار** | بدون «به تعویق انداختن» با دلیل و تاریخ، کاربر هشدار را خاموش می‌کند. |
| ۴ | **«انجام شد» وجود ندارد** | بدون آن، چرخه بعدی از کجا شروع شود؟ این حلقه، قلب محصول است. |
| ۵ | **سابقه سرویس** | بدون تاریخچه، اپ هیچ‌وقت نمی‌داند دفعه قبل کِی بود؛ همه محاسبات حدس می‌شوند. |
| ۶ | **حالت خالی و مجوز اعلان** | کاربر بدون خودرو یا با اعلان ردشده، به بن‌بست می‌رسد. |
| ۷ | **OCR بدون تأیید** | عدد غلط، مبنا همه محاسبات را خراب می‌کند و بی‌اعتمادی می‌سازد. |
| ۸ | **Splash + کوییز قبل از ارزش** | کاربر هنوز نفهمیده چه می‌گیرد، باید ۵ قدم ثبت‌نام طی کند. |

## ۲. فلوی پیشنهادی MVP

تفاوت اصلی: **هیچ ثبت‌نامی نیست، هیچ Splashی نیست، و ارزش در ۶۰ ثانیه دیده می‌شود.**

```mermaid
flowchart TD
    S(["باز کردن اپ"]) --> G{"گاراژ خالی است؟"}

    G -->|"بله"| W["ثبت خودرو در ۳ فیلد<br/>برند · مدل/سال · کیلومتر"]
    W --> KQ{"کیلومتر را می‌دانم؟"}
    KQ -->|"نه"| GUESS["حدس از سال خودرو<br/>با برچسب «تقریبی»"]
    KQ -->|"بله"| NF
    GUESS --> NF{"مدل در کاتالوگ هست؟"}
    NF -->|"بله"| AHAA["کارت اقدام بعدی<br/>«روغن: ۸۰۰ کیلومتر دیگر»"]
    NF -->|"نه"| ALT["نزدیک‌ترین مدل + برچسب تخمینی<br/>+ ثبت درخواست بررسی"]
    ALT --> AHAA
    AHAA --> HOME

    G -->|"خیر"| HOME["گاراژ<br/>خودرو فعال · کیلومتر · اقدام بعدی"]

    HOME --> DET["جزئیات قطعه<br/>بازه + منبع + سطح اطمینان"]
    HOME --> HIST["تایم‌لاین سرویس"]
    HOME --> CAR["افزودن / ویرایش خودرو (سقف ۲)"]
    HOME --> SET["تنظیمات و سلب مسئولیت"]

    DET --> ACT{"اقدام کاربر"}

    ACT -->|"انجام شد"| DONE["ثبت کیلومتر + تاریخ<br/>هزینه اختیاری"]
    ACT -->|"به تعویق"| SNZ["تعویق با دلیل + تاریخ بازگشت"]
    ACT -->|"کیلومتر را آپدیت کنم"| KM["صفحه‌کلید عددی درشت<br/>+/− ۱۰۰۰"]

    KM --> RC["محاسبه مجدد وضعیت همه قطعات"]
    DONE --> RC
    SNZ --> RC
    RC --> HOME

    RC --> DUE{"قطعه‌ای سررسید؟"}
    DUE -->|"بله"| ALERT["کارت هشدار + اعلان محلی"]
    DUE -->|"خیر"| OK["«همه‌چیز مرتب است»<br/>+ موعد بعدی"]
    ALERT --> DET
    OK --> HOME

    classDef added fill:#ecfdf5,stroke:#059669,color:#065f46;
    classDef core fill:#eff6ff,stroke:#2563eb,color:#1e40af;
    class AHAA,DONE,SNZ,HIST,ALT,GUESS added;
    class DET,KM,RC,ALERT core;
```

**قاعده اعلان:** کیلومتر را به تاریخ تبدیل کن — `روزهای باقی‌مانده = (کیلومتر موعد − کیلومتر فعلی) ÷ میانگین کیلومتر روزانه`. اعلان محلی، حداکثر یکی در هفته، با یک دکمه اصلی.

## ۳. چرخه عمر یک قطعه

```mermaid
stateDiagram-v2
    direction LR
    state "نامشخص" as unknown
    state "سالم" as ok
    state "نزدیک موعد" as near
    state "سررسیده" as due
    state "به تعویق افتاده" as snoozed
    state "انجام‌شده" as done

    [*] --> unknown
    unknown --> ok: ثبت کیلومتر و تاریخ
    ok --> near: عبور از ۸۰٪ بازه
    near --> due: عبور از بازه
    due --> done: «انجام شد» + کیلومتر
    done --> ok: شروع چرخه جدید
    due --> snoozed: تعویق با دلیل
    snoozed --> due: رسیدن تاریخ تعویق
    near --> ok: تعویض زودتر از موعد
    done --> [*]: حذف خودرو
```

**قاعده نمایش:** همیشه سه چیز با هم نشان داده شود — بازه، منبع، و سطح اطمینان. یک رنگ قطعی بدون منبع، ادعای بی‌پشتوانه است.

| وضعیت | رنگ | جمله پیشنهادی |
|---|---|---|
| سالم | سبز | «تا حدود ۲٬۳۰۰ کیلومتر دیگر» |
| نزدیک | زرد | «برنامه‌ریزی کن؛ حدود ۴۰۰ کیلومتر مانده» |
| سررسید | قرمز | «گذشته از موعد — تا ۱٬۰۰۰ کیلومتر دیگر بی‌خطر است» |
| نامشخص | خاکستری | «کیلومترت را ثبت کن تا دقیق حساب کنم» |
